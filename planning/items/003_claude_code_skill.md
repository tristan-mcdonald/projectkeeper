# A Claude Code skill or plugin

## Why

The agent instructions snippet tells an agent where to start, but each session still has to work
out how to carry out common tasks within the rules. A skill or plugin could provide them as
commands.

## What we know

- Candidate commands: start a session (read the index, the decisions, and an item); start an
  item; add an item; record a decision; run a triage session over the ideas; close an item.
- Agreed on 2026-10-16 as a later step, and only if it proves useful. Wait for the lessons in
  [002](002_learn_from_real_use.md) before deciding.

## Open questions

- A skill, a plugin, or both? Should other agents get an equivalent?
- Does it duplicate the snippet, or replace it?
