# Planning

projectkeeper's own backlog. Each piece of work has its own file in `items/`, and this page is the
index, in priority order. Decisions which shape more than one item are recorded in
`decisions.md`.

This folder follows [projectkeeper 1.0](../SPEC.md).

## Start of a session

1. Read this page and `decisions.md`.
2. Open the item being worked on, and only the items it links to.
3. Check `git log` for anything which has changed since the item was last updated.
